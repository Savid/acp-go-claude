---
title: "Prompt Streaming"
description: "How Claude stream output becomes ACP updates"
---

Claude stream events are mapped to ACP session updates for assistant text,
thoughts, tool calls, tool results, plans, usage, and session info.

Permission requests are sent as permission prompts. User-facing questions from
Claude are sent through ACP elicitation only when the initialized client
advertises elicitation support.

Raw Claude events are not sent by default. Enable them per session with
`_meta.claude.rawEvent.enabled`.
