---
title: "Sessions"
description: "ACP session lifecycle"
---

The adapter implements ACP session create, load, resume, list, prompt, cancel,
close, and delete flows. Session identifiers are ACP session IDs and are also
used as the durable store key.

Forking is exposed only through `_claude/session/fork`.

Durable storage uses:

```go
type SessionKey struct {
    SessionID string
    Subpath   string
}
```

The main transcript uses an empty subpath. Additional transcript files use a
safe relative subpath under the same session ID.
