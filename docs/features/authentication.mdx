---
title: "Authentication"
description: "Claude account ownership"
---

The adapter does not manage Claude Code account state. Claude authentication is
owned by the local Claude Code installation selected by `-home` or `WithHome`.

ACP initialize reports no adapter auth methods. ACP logout only clears
adapter-owned state and closes adapter sessions.

For tests and automation, pass Claude environment variables with `WithEnv` or
through the process environment used to launch the binary.
