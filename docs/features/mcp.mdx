---
title: "MCP"
description: "MCP server declarations accepted by the adapter"
---

The adapter accepts stdio and HTTP MCP server declarations from ACP session
requests and maps them to Claude configuration.

Unsupported MCP transports fail the session request with an explicit invalid
params error. The adapter does not open ACP-transport MCP channels.

```go
servers := []acp.McpServer{
    claudeacp.StdioMCPServer("tools", "node", []string{"server.js"}, nil),
    claudeacp.HTTPMCPServer("remote", "https://example.test/mcp", nil),
}
```
