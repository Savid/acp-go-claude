---
title: "Permissions"
description: "Claude permissions through ACP"
---

Claude tool permission requests are mapped to ACP permission prompts. The
adapter preserves session-scoped permission decisions and never silently grants
tool access.

Default permission behavior can be set with:

```go
claudeacp.WithClaudeDefaultPermissionMode("default")
```

Elicitation is separate from permissions. Tool access decisions use permission
prompts; user questions use elicitation only when the client supports it.
