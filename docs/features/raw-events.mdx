---
title: "Raw Events"
description: "Opt into bounded, gap-detectable notifications of raw Claude stream frames"
---

Raw events expose Claude's underlying stream-json frames to a host that needs to
observe or debug the native protocol. They are off by default and carry no
authoritative meaning — the ACP session updates remain the source of truth.

## Enabling per session

Raw events are opt-in per session, set when creating or loading it:

```go
req := acp.NewSessionRequest{
	Cwd: cwd,
	Meta: map[string]any{
		"claude": map[string]any{
			"rawEvent": map[string]any{"enabled": true},
		},
	},
}
```

The helper `WithSessionRawEvents(true)` sets the same metadata.

## Notification shape

Notifications arrive on `_claude/rawEvent` and carry `sessionId`, `sequence`,
`source` (always `claude`), and `event`. The `sequence` is per session and
strictly contiguous across successful deliveries. A failed delivery does not
consume a number; the next successful delivery receives the next number. This
counter is independent of the lifecycle stream, whose sequence is claimed
before delivery.

## Bounding and truncation

Payloads are capped at 64 KiB (65536 bytes) measured on the full notification
payload. An event is never dropped and never fails the turn. An oversized event
still consumes its sequence and is emitted with `event` replaced by a fixed
marker:

```json
{ "truncated": true, "reason": "oversize", "maxBytes": 65536, "sizeBytes": 0 }
```

`sizeBytes` is the byte length of the original marshalled payload. An event that
cannot be marshalled is emitted with `{ "truncated": true, "reason":
"unserializable", "maxBytes": 65536 }` (no `sizeBytes`). Because the marker still
consumes a sequence number, the stream stays contiguous even when a frame is
replaced.

## Image and URL hygiene

Raw events are diagnostic, so they never carry a second copy of image bytes.
Image blocks inside a raw frame have their base64 data removed and replaced with
an `imageMetadata` object holding `mimeType`, `sizeBytes`, `sha256`, and, when
structurally readable, `width` and `height`. `data:` URIs are collapsed to
`data:[redacted]`, and HTTP(S) `url`/`uri` values lose their query and fragment
so signed tokens never persist in diagnostics. Typed image content is delivered
through normal session updates, not raw events — see
[typed image output](/docs/features/session-store).
