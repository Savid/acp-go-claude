---
title: "Raw Events"
description: "Opt-in Claude stream event notifications"
---

Raw Claude stream events are off by default. Enable them when creating or
loading a session:

```go
req := acp.NewSessionRequest{
    Cwd: cwd,
    Meta: map[string]any{
        "_meta": map[string]any{
            "claude": map[string]any{
                "rawEvent": map[string]any{"enabled": true},
            },
        },
    },
}
```

Notifications use `_claude/rawEvent` and contain `sessionId`, `sequence`,
`source`, and `event`. The `sequence` is per session and strictly contiguous:
every event consumes exactly one sequence number, so a host can detect a gap.

Payloads are capped at 64 KiB (65536 bytes) measured on the full notification
payload. An event is never dropped and never fails the turn: an oversized event
still consumes its sequence and is emitted with `event` replaced by the fixed
marker

```json
{ "truncated": true, "reason": "oversize", "maxBytes": 65536, "sizeBytes": 0 }
```

where `sizeBytes` is the byte length of the original marshalled payload. An event
that cannot be marshalled is emitted with `{ "truncated": true, "reason":
"unserializable", "maxBytes": 65536 }` (no `sizeBytes`). Because the marker
still consumes the sequence, the stream stays contiguous even when an event is
replaced.
