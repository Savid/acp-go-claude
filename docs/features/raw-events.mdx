Portable clients should rely on normal
[ACP session updates](/docs/reference/updates). Some hosts also need
provider-native Claude
[stream-json rows](https://code.claude.com/docs/en/agent-sdk/streaming-output)
for debugging, archival, or custom UI.

Raw event selection is per session in both
[run modes](/docs/get-started/run-modes). Configure it in ACP request
metadata, not as a process flag or Go option.

## Capability

The agent advertises:

```json
{
  "claude": {
    "sdkMessages": {
      "scope": "session",
      "method": "_claude/sdkMessage",
      "enabledBy": "_meta.claude.emitRawSDKMessages"
    }
  }
}
```

## Enable all raw messages

```json
{
  "_meta": {
    "claude": {
      "emitRawSDKMessages": true
    }
  }
}
```

Add this metadata to [session start requests](/docs/core/sessions#create).

## Enable selected raw messages

```json
{
  "_meta": {
    "claude": {
      "emitRawSDKMessages": [
        { "type": "assistant" },
        { "type": "result" },
        { "type": "system", "subtype": "init" },
        { "type": "user", "origin": "tool_result" }
      ]
    }
  }
}
```

Filters match `type`, optional `subtype`, and optional `origin.kind`.
Internal Claude control messages with `type: "control_request"` or
`type: "control_response"` are not emitted. See
[Metadata](/docs/reference/meta#raw-event-emission) for the `_meta` shape and
[ACP methods](/docs/reference/acp-methods#extension-notifications) for the
extension notification.

## Notification payload

```json
{
  "sessionId": "00000000-0000-4000-8000-000000000000",
  "message": { "type": "assistant" },
  "rawJSON": "{\"type\":\"assistant\"}"
}
```

`rawJSON` is included when the original stream-json row is available. The
normal portable mapping still happens through
[Prompt streaming](/docs/core/prompt-streaming).

Raw events include provider-native frames that the portable mapper hides, such
as Claude's internal `StructuredOutput` tool call when
[`outputFormat`](/docs/reference/meta#session-options) is configured.
