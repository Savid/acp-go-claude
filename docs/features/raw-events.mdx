---
title: "Raw Events"
description: "Opt-in Claude stream event notifications"
---

Raw Claude stream events are off by default. Enable them when creating or
loading a session:

```go
req := acp.NewSessionRequest{
    Cwd: cwd,
    Meta: map[string]any{
        "_meta": map[string]any{
            "claude": map[string]any{
                "rawEvent": map[string]any{"enabled": true},
            },
        },
    },
}
```

Notifications use `_claude/rawEvent` and contain `sessionId`, `sequence`,
`source`, and `event`. Events over the adapter cap are dropped.
