---
title: "Session Store"
description: "Configure the authoritative transcript store used for session restore and discovery"
---

Every agent has a `SessionStore`. By default it is a private in-memory store, so
sessions remain restorable only for that agent instance. Provide a host store
when session authority must survive process restarts or move between machines —
for example a database or object store.

## Wiring a store

Replace the default store with `WithSessionStore`; bound restore and list reads
with `WithSessionStoreLoadTimeout`. A ready-made in-memory implementation ships
for tests and small hosts:

```go
store := claudeacp.NewInMemorySessionStore()

err := claudeacp.Serve(ctx, input, output,
	claudeacp.WithSessionStore(store),
	claudeacp.WithSessionStoreLoadTimeout(5*time.Second),
)
```

The adapter mirrors Claude transcript rows into the store as the turn streams
and uses the store as the sole authority for `session/list`, `session/load`,
`session/resume`, and inactive-session fork. Restore always hydrates the
authoritative rows into an isolated temporary Claude config directory under the
scratch directory (default: system temp).

Claude's native transcript is a process cache, not a discovery or restore
authority. An inactive native transcript whose session id has no main store
rows is ignored, removed when addressed, and reported as an unknown session.
If the same id is still actively bound in this Agent, a store-authoritative
load still reports unknown but leaves that live binding and its native
transcript untouched; prompts on the already-bound route remain usable.

## The store contract

The format constant and key type are stable public identifiers:

```go
const SessionStoreFormat = "claude-transcript-jsonl-v1"

type SessionKey struct {
	SessionID string
	Subpath   string
}
```

A store implements six methods:

| Method | Role |
| --- | --- |
| `Append` | Append transcript rows for a key. |
| `Load` | Read all rows for a key. |
| `Replace` | Atomically replace a full generation of a session's files. |
| `Delete` | Remove a key (and its subkeys for the main key). |
| `ListSessions` | Enumerate sessions for `session/list`. |
| `ListSubkeys` | Enumerate a session's non-main subpaths. |

The main transcript uses the empty subpath (`SessionStoreMainSubpath`);
subagent transcripts mirror under safe relative subpaths of the same session id.
`Replace` MUST include the main key exactly once. Session summaries report
`UpdatedAtUnixMilli` in Unix milliseconds.

<Note>
`WithSessionStoreLoadTimeout` bounds store reads used by restore and listing.
Set it when your store can hang (network round-trips), or a slow backend will
stall `session/load`, `session/resume`, fork, and `session/list`.
</Note>
