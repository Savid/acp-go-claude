---
title: "Session Store"
description: "Durable transcript storage contract"
---

`WithSessionStore` installs a host-owned store. The format constant is:

```go
const SessionStoreFormat = "claude-transcript-jsonl-v1"
```

The store key is:

```go
type SessionKey struct {
    SessionID string
    Subpath   string
}
```

The interface includes `Append`, `Load`, `Replace`, `Delete`, `ListSessions`,
and `ListSubkeys`. `Replace` supplies a full generation of transcript files for
one session. `Delete` records removal semantics through the store
implementation. Session summaries use Unix milliseconds in
`UpdatedAtUnixMilli`.
