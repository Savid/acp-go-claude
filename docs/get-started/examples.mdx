Three runnable reference clients live under `examples/`. Each is a real ACP
client, not a stub, and each drives the adapter through a full initialize →
session → prompt flow.

## Available examples

| Example | What it does |
| --- | --- |
| `examples/minimal-client` | Starts the adapter, sends one prompt, prints the streamed reply. |
| `examples/interactive-chat` | A small interactive terminal client for multi-prompt sessions. |
| `examples/resume-from-file` | Loads a Claude transcript JSONL into a `SessionStore`, restores the session, and prompts it. |

## Running them

The examples are repo-relative, so clone the repository first:

```sh
git clone https://github.com/savid/acp-go-claude && cd acp-go-claude
```

Send a single prompt:

```sh
go run ./examples/minimal-client "Reply with ACP_EXAMPLE_OK"
```

Resume from the shipped transcript fixture. The `-file` flag defaults to the
bundled fixture, so both forms are equivalent:

```sh
go run ./examples/resume-from-file -file ./examples/resume-from-file/session.jsonl
```

`resume-from-file` also accepts `-session`, `-cwd`, and `-prompt` to override
the session id, working directory, and follow-up prompt. See
[Session store](/docs/features/session-store) for how the transcript is loaded
back into a session.
