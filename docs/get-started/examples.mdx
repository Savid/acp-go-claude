title: "Examples"
description: "Included example programs"
---

| Example | Purpose |
| --- | --- |
| `examples/minimal-client` | Starts the adapter, sends one prompt, and prints the response. |
| `examples/interactive-chat` | Runs a small interactive terminal client. |
| `examples/resume-from-file` | Reads JSONL into a `SessionStore`, loads the session, and prompts it. |

Run any example from the repository root:

```sh
go run ./examples/minimal-client "Reply with ACP_EXAMPLE_OK"
```
