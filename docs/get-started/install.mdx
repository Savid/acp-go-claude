---
title: "Install"
description: "Install or build the ACP adapter"
---

Install from source:

```sh
go install github.com/savid/acp-go-claude/cmd/acp-go-claude@latest
```

Build the local checkout:

```sh
go build ./cmd/acp-go-claude
```

The adapter launches `claude` from `PATH` unless a host provides `-path` or
`WithExecutablePath`. Use `-home` or `WithHome` to select the Claude config
directory for launched sessions.
