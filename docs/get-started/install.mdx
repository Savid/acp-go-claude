---
title: "Install"
description: "Install the binary, add the library, or build from a checkout"
---

The adapter ships as both a CLI and an importable Go package.

## Install the CLI

```sh
go install github.com/savid/acp-go-claude/cmd/acp-go-claude@latest
```

The command speaks ACP over stdin/stdout; an ACP host launches it as a
subprocess.

## Add the library

```sh
go get github.com/savid/acp-go-claude
```

Embed the adapter with `claudeacp.Serve`. Hosts that own native containment can
also provide `WithHostAuthority`; standalone command execution remains ordinary
same-identity execution.

## Build from a checkout

```sh
go build ./cmd/acp-go-claude
```

The adapter launches `claude` from `PATH` unless `-path`
(`WithExecutablePath`) selects another executable. Use `-home` (`WithHome`) to
select `CLAUDE_CONFIG_DIR`. Claude Code must be version 2.0.0 or newer and
authenticated for the selected home or environment; the adapter probes the
version at each native start.
