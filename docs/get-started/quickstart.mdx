---
title: "Quickstart"
description: "Run a local ACP client against Claude Code"
---

Install the command:

```sh
go install github.com/savid/acp-go-claude/cmd/acp-go-claude@latest
```

Run the minimal example:

```sh
go run ./examples/minimal-client "Reply with hello from ACP"
```

Run the interactive example:

```sh
go run ./examples/interactive-chat
```

Both examples start an ACP connection, initialize the agent, create a session,
send prompts, and print streamed assistant output.
