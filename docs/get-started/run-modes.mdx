## Standalone subprocess

`acp-go-claude` speaks ACP JSON-RPC over stdin/stdout. Diagnostics go to
stderr. Native Claude commands run ordinarily as the command's current
identity.

```sh
acp-go-claude -path /usr/local/bin/claude -home /var/lib/acp-go-claude -model sonnet
```

Use `-scratch-dir` to choose the parent for adapter-owned temporary files and
`-seed-file <relpath>=<hostpath>` to copy a file into each materialized Claude
home before launch.

## Embedded host

Call `Serve` when the host owns the ACP streams. Omitting `WithHostAuthority`
keeps the same ordinary execution behavior as the command. Supplying
`WithHostAuthority` delegates every native launch and prepared-tree boundary to
the host:

```go
err := claudeacp.Serve(ctx, input, output,
	claudeacp.WithExecutablePath("claude"),
	claudeacp.WithHome("/var/lib/acp-go-claude"),
	claudeacp.WithHostAuthority(authority),
)
```

The authority is mandatory once supplied. Missing methods, unusable returned
process streams, or authority loss fail closed; no direct-launch fallback is
attempted.

## Flag and option equivalents

| Flag | Go option |
| --- | --- |
| `-path` | `WithExecutablePath` |
| `-home` | `WithHome` |
| `-scratch-dir` | `WithScratchDir` |
| `-provider-auth-root` | `WithProviderAuthRoot` |
| `-provider-auth-direct-home` | `WithProviderAuthDirectHome` |
| `-model` | `WithDefaultModel` |
| `-seed-file` | `WithSeedFiles` |
| `-claude-bare` | `WithClaudeBareMode` |
| `-claude-hide-auth` | `WithClaudeHideAuth` |
| `-claude-permission-mode` | `WithClaudeDefaultPermissionMode` |
| `-claude-settings-file` | `WithClaudeSettingsFile` |
| `-claude-system-prompt` | `WithClaudeDefaultSystemPrompt` |

`-debug` configures the command's logger and `-version` prints the binary
version. Embed-only options, including `WithHostAuthority`, session stores,
turn and concurrency limits, image limits, and telemetry providers, have no CLI
flag.

See [Security](/docs/operations/security) for the launch, prepare, reclaim,
revoke, and settlement ordering.
