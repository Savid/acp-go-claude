## Standalone

`acp-go-claude` speaks ACP over stdin/stdout:

```sh
acp-go-claude -path /usr/local/bin/claude -home /tmp/claude-home -model sonnet
```

## Embedded

```go
err := claudeacp.Serve(ctx, input, output,
    claudeacp.WithExecutablePath("/usr/local/bin/claude"),
    claudeacp.WithHome("/tmp/claude-home"),
    claudeacp.WithDefaultModel("sonnet"),
)
```

Use `WithSessionStore` when the host wants session storage outside the local
Claude project directory.
