## Telemetry wiring

Embedded hosts supply OpenTelemetry providers with `WithTracerProvider`,
`WithMeterProvider`, and `WithTextMapPropagator`. The standalone binary
configures exporters from environment variables when OpenTelemetry support is
compiled in. Providers a host passes stay owned by the host, including
`ForceFlush` and `Shutdown`.

Logs go to stderr so stdout stays reserved for ACP frames; enable debug logging
with `-debug` (`WithLogger` for a custom logger). Telemetry records lifecycle
timing, request outcomes, and counters, and by default avoids recording prompt
text, tool inputs, tool outputs, and raw Claude event bodies.

## Diagnosing turn failures

A failed prompt returns a `claude_turn_failed` error whose `cause` tells you
where to look. The [failure contract](/docs/reference/acp-methods) defines the
full shape; use the `cause` to route the investigation:

| Cause | First thing to check |
| --- | --- |
| `process_exit` | The `message` carries only the exit status; confirm the `claude` CLI is installed, is version 2.0.0+, and is authenticated. |
| `transport` | A stream broke mid-turn; the `message` names the cause the adapter observed. Check for client disconnects or a Claude process killed out from under the adapter. |
| `provider` | Claude itself reported an error (including auth); the `message` carries the cause its result frame named. Inspect provider-side logs for anything beyond it, because the rest of the frame is not copied onto the wire. |
| `timeout` | A `WithTurnTimeout` deadline expired; raise the bound or investigate why the turn ran long. |

<Note>
A user cancel that coincides with a `WithTurnTimeout` expiry resolves as a
successful `cancelled` response, not a `timeout` failure. If you expect timeouts
but see cancellations, the client is cancelling first. Both outcomes wait for
the selected native process boundary. A `transport` failure mentioning
incomplete containment means the adapter retained prepared roots and disabled
lazy relaunch and new native session admission. Investigate host-authority
records and lease processes before recovery.
</Note>
