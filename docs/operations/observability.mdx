---
title: "Observability"
description: "Logs, metrics, and traces"
---

Embedded hosts can provide OpenTelemetry providers with `WithTracerProvider`,
`WithMeterProvider`, and `WithTextMapPropagator`.

The command can configure exporters from environment variables when
OpenTelemetry support is available in the build. Logs are written to stderr so
stdout remains reserved for ACP frames.

Telemetry records lifecycle timing, request outcomes, and counters. It avoids
recording prompt text, tool inputs, tool outputs, and raw Claude event bodies by
default.
