## Ordinary execution

When `WithHostAuthority` is omitted, Claude runs as the adapter process's own
identity. The adapter captures a sanitized ambient environment, applies
`WithEnv`, and starts the configured executable directly. `WithHome` selects
the Claude config directory. Reserved home, XDG, and adapter-private variables
cannot be overridden through `WithEnv` or session metadata.

## Host authority

An embedded host that owns native containment supplies `WithHostAuthority`.
This is a strict boundary: an unusable supplied authority fails with
`ErrHostAuthorityUnavailable`, and the adapter never falls back to a direct
process launch.

Every native launch uses `HostAuthority.StartNative`, including the per-start
Claude version probe, session processes, provider-auth commands, usage probes,
and platform credential checks. Each `NativeRequest` contains the logical
executable, complete argument vector, canonical environment, and working
directory. The environment starts from `HostAuthority.NativeEnvironment` and
then receives the adapter's validated overlays.

The adapter writes all settings, copied config, session transcript seeds, MCP
configuration, and browser-launcher shims before calling
`PrepareNativeTree`. It does not access a prepared tree again until
`ReclaimNativeTree` succeeds. Session-residence disposal owns removal of a
prepared transcript tree; session deletion does not reopen it.

Shutdown first closes protocol stdin, then waits for the native process. If it
does not exit within the grace period, the adapter calls `Revoke` and waits for
terminal settlement. Stream frames remain readable until `Wait` completes.

`ErrNativeTreeBusy` means live lease processes still prevent reclamation; the
tree is retained. Any other uncertain reclaim failure is reported as
`ErrContainmentIncomplete`, and the tree is likewise retained. Either
`ErrContainmentIncomplete` or `ErrHostAuthorityUnavailable` stops new native
session admission for that agent.

## Credentials and logs

Claude account material stays in the selected Claude config directory. The
adapter does not log authentication material, prompts, tool input, tool output,
or raw Claude event bodies by default. ACP logout clears adapter-owned state;
native account changes occur only through the explicitly selected provider-auth
operation.
