---
title: "Security"
description: "Security boundaries"
---

Claude account material remains in the Claude config directory selected by the
host. The adapter does not log secrets, prompt text, tool payloads, or raw event
content by default.

Permission prompts are load-bearing. The adapter does not bypass them and keeps
permission decisions scoped to the session.

Native Claude child processes are started in their own process group and are
configured to receive a parent-death signal on Unix platforms.

MCP server declarations are validated before launch. Unsupported transports are
rejected before Claude is started.
