---
title: "Overview"
description: "Claude Code as an Agent Client Protocol agent"
---

`acp-go-claude` runs Claude Code behind an Agent Client Protocol JSON-RPC
connection. Hosts can launch the `acp-go-claude` binary over stdio or embed the
Go package and call `claudeacp.Serve`.

The adapter owns protocol mapping, Claude subprocess lifecycle, streaming
updates, permission prompts, elicitation, model configuration, optional raw
events, and optional durable session storage. Claude authentication and account
state stay with the local Claude Code installation.

Public extension methods are intentionally narrow:

| Method | Purpose |
| --- | --- |
| `_claude/session/fork` | Fork a stored or active session. |
| `_claude/rawEvent` | Emit opt-in bounded Claude stream events. |

The public metadata namespace is `_meta.claude`.
