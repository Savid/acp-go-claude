`acp-go-claude` exposes the local
[Claude Code CLI](https://code.claude.com/docs/en/overview) as an
[Agent Client Protocol](https://agentclientprotocol.com/) agent. It speaks ACP
over [JSON-RPC streams](https://agentclientprotocol.com/protocol/transports),
starts `claude` subprocesses on demand, maps
[ACP prompts](https://agentclientprotocol.com/protocol/prompt-turn) and client
callbacks into Claude stream-json/control protocol messages, and streams
[ACP session updates](/docs/reference/updates) back to the host.

Use it when you want an ACP-compatible Claude agent without depending on a
Claude-specific Go SDK.

<Note>
  This project wraps the local `claude` CLI. Authentication, model availability,
  Claude settings, tool behavior, and transcript persistence are ultimately
  governed by the installed Claude Code version and the user's Claude
  configuration.
</Note>
