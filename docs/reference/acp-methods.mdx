---
title: "ACP Methods"
description: "Implemented ACP methods and extensions"
---

Core methods include initialize, session create/load/resume/list/delete,
prompt, cancel, close, authenticate, logout, and configuration methods
implemented by the ACP SDK connection.

Claude extensions:

| Method | Direction |
| --- | --- |
| `_claude/session/fork` | client to agent |
| `_claude/rawEvent` | agent to client |

Unsupported methods return a uniform JSON-RPC method-not-found error.
