---
title: "CLI"
description: "Command-line flags"
---

`acp-go-claude` speaks ACP over stdin/stdout.

```sh
acp-go-claude -path /usr/local/bin/claude -home /tmp/claude-home -model sonnet -claude-permission-mode default
```

Flags:

| Flag | Purpose |
| --- | --- |
| `-path` | Claude CLI executable. |
| `-home` | Claude config directory for launched sessions. |
| `-model` | Default model. |
| `-debug` | Emit debug logs to stderr. |
| `-version` | Print version and exit. |
| `-claude-bare` | Launch Claude with `--bare`. |
| `-claude-hide-auth` | Hide Claude account helper text. |
| `-claude-permission-mode` | Set the default Claude permission mode. |
| `-claude-system-prompt` | Set the default system prompt. |
