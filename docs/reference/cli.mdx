---
title: "CLI"
description: "Every flag the acp-go-claude binary accepts and what it maps to"
---

`acp-go-claude` speaks ACP over stdin/stdout. Flags use Go's single-dash syntax.

```sh
acp-go-claude -path /usr/local/bin/claude -home /tmp/claude-home -model sonnet -claude-permission-mode default
```

## Flags

| Flag | Purpose |
| --- | --- |
| `-path` | Claude CLI executable (default: search `PATH`). |
| `-home` | Claude config directory (`CLAUDE_CONFIG_DIR`) for launched sessions. |
| `-model` | Default Claude model. |
| `-seed-file` | Write a host file into the config dir as `<relpath>=<hostpath>`; repeatable. Requires `-home`. |
| `-settings-file` | Settings-overlay relpath under the config dir passed as `--settings`. Requires `-home`. |
| `-claude-bare` | Launch Claude with `--bare`. |
| `-claude-hide-auth` | Hide Claude subscription terminal auth methods. |
| `-claude-permission-mode` | Default Claude permission mode. |
| `-claude-system-prompt` | Default system prompt. |
| `-debug` | Emit debug logs to stderr. |
| `-version` | Print adapter version and exit. |

<Note>
Not every embedded option has a flag. Turn timeouts, concurrency limits,
OpenTelemetry providers, and the session store are embedded-Go only — configure
them with the [Go API](/docs/reference/go-api) options such as `WithTurnTimeout`
and `WithSessionStore`.
</Note>
