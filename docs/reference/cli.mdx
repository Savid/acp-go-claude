---
title: "CLI"
description: "Command-line flags accepted by acp-go-claude"
---

`acp-go-claude` speaks ACP over stdin/stdout. Flags use Go's single-dash
syntax.

## Invocation

```sh
acp-go-claude -path /usr/local/bin/claude -home /tmp/claude-home -model sonnet
```

The command reads ACP requests from standard input, writes ACP responses and
notifications to standard output, and reserves standard error for diagnostics.

## Flags

| Flag | Meaning |
| --- | --- |
| `-path` | Claude CLI executable; empty uses `claude` from `PATH`. |
| `-home` | Claude config directory. |
| `-scratch-dir` | Parent for adapter-owned temporary roots; empty uses the system temporary directory. |
| `-provider-auth-root` | Host-owned provider-auth ledger root. |
| `-provider-auth-direct-home` | Exact Claude config directory a native-login disconnect may clear. |
| `-model` | Default Claude model. |
| `-claude-bare` | Launch Claude with `--bare`; requires compatible static authentication. |
| `-claude-permission-mode` | Default Claude permission mode. |
| `-claude-system-prompt` | Default Claude system prompt. |
| `-claude-hide-auth` | Hide Claude subscription sign-in from the auth catalog. |
| `-seed-file <relpath>=<hostpath>` | Copy a file into each materialized Claude home; repeatable. |
| `-claude-settings-file` | Settings overlay path relative to `-home`. |
| `-debug` | Write debug logs to stderr. |
| `-version` | Print the adapter version and exit. |

## Execution boundary

The standalone command uses ordinary same-identity native execution. Hosts that
provide a native authority embed the Go package and use `WithHostAuthority`.
The command-line surface does not accept native-authority configuration; that
boundary is an in-process Go API.
