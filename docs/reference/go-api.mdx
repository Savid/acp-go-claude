The authoritative signatures and doc comments are on
[pkg.go.dev](https://pkg.go.dev/github.com/savid/acp-go-claude). The primary
entry point is:

```go
err := claudeacp.Serve(ctx, input, output,
	claudeacp.WithExecutablePath("claude"),
	claudeacp.WithHome("/var/lib/acp-go-claude"),
	claudeacp.WithSessionStore(store),
)
```

`Serve` closes the agent before returning. Close errors take precedence over
EOF or caller cancellation.

## HostAuthority

`WithHostAuthority(authority)` delegates native work to a host:

```go
type HostAuthority interface {
	NativeEnvironment() map[string]string
	PrepareNativeTree(context.Context, string) error
	ReclaimNativeTree(context.Context, string) error
	StartNative(context.Context, NativeRequest) (NativeProcess, error)
}
```

`NativeRequest` carries `Executable`, `Arguments`, `Environment`, and
`WorkingDirectory`. `NativeProcess` exposes `Stdin`, `Stdout`, `Stderr`,
`Wait(context.Context) (NativeResult, error)`, and `Revoke(context.Context)
error`. `NativeResult` carries `ExitCode`, `Signal`, and `Revoked`.

The public boundary errors are:

- `ErrHostAuthorityUnavailable`: a supplied authority cannot provide the
  selected operation.
- `ErrContainmentIncomplete`: native shutdown or tree reclamation is uncertain.
- `ErrNativeTreeBusy`: reclamation is refused because lease processes are live.

Supplying an authority is strict and never enables direct-launch fallback.
Omitting it selects ordinary same-identity execution.

## Common options

| Option group | Options |
| --- | --- |
| Native paths and environment | `WithExecutablePath`, `WithHome`, `WithScratchDir`, `WithEnv`, `WithSeedFiles` |
| Host boundaries | `WithHostAuthority`, `WithInputHandoffRoot` |
| Session behavior | `WithDefaultModel`, `WithTurnTimeout`, `WithConcurrencyLimits`, `WithImageLimits` |
| Durable sessions | `WithSessionStore`, `WithSessionStoreLoadTimeout` |
| Provider auth | `WithProviderAuthRoot`, `WithProviderAuthDirectHome` |
| Claude behavior | `WithClaudeDefaultPermissionMode`, `WithClaudeDefaultSystemPrompt`, `WithClaudeHideAuth`, `WithClaudeBareMode`, `WithClaudeSettingSources`, `WithClaudeSettingsFile`, `WithClaudeDirectAPI`, `WithClaudeAllowSkipPermissionsFlag`, `WithClaudeInitializeTimeout`, `WithClaudeControlHandlerTimeout` |
| Identity and diagnostics | `WithAgentName`, `WithAgentTitle`, `WithAgentVersion`, `WithLogger` |
| Telemetry | `WithTracerProvider`, `WithMeterProvider`, `WithTextMapPropagator` |

`WithClaudeDirectAPI(false)` prevents the adapter itself from making the
Anthropic fallback request used by `_claude/rateLimits`; native Claude network
behavior is unaffected.

`ConcurrencyLimits` caps active sessions and concurrent outbound client calls.
`ImageLimits` controls decoded input and emitted output byte limits.

## Requests and session storage

Request builders such as `NewSessionRequest`, `TextPromptRequest`, and
`DeleteSessionRequest` construct ACP request values with the adapter metadata
shape.

`PromptRequest(sessionID, turnNonce, blocks...)` and
`TextPromptRequest(sessionID, turnNonce, text)` require a fresh non-empty turn
nonce. `CancelRequest(sessionID, turnNonce)` must repeat the active turn's
nonce; a different or absent nonce is refused before the native process is
interrupted.

The durable surface consists of `SessionStore`, `SessionStoreEntry`,
`SessionKey`, `SessionSummary`, `SessionStoreReplacement`,
`InMemorySessionStore`, `SessionStoreFormat`, and `SessionStoreMainSubpath`.
