The full, authoritative API — signatures, types, and doc comments — is on
[pkg.go.dev](https://pkg.go.dev/github.com/savid/acp-go-claude). This page indexes
the public surface; it does not restate godoc.

## Entry point

`Serve(ctx, input, output, opts...)` runs the agent over a pair of JSON-RPC
streams:

```go
err := claudeacp.Serve(ctx, input, output,
	claudeacp.WithExecutablePath("/usr/local/bin/claude"),
	claudeacp.WithHome("/tmp/claude-home"),
	claudeacp.WithDefaultModel("sonnet"),
	claudeacp.WithClaudeDefaultPermissionMode("default"),
	claudeacp.WithSessionStore(store),
)
```

`Serve` closes the agent before it returns. If shutdown fails, that close error
takes precedence over EOF or context cancellation. In particular,
`errors.Is(err, claudeacp.ErrProcessTreeUnproven)` means the adapter could not
prove every native Claude descendant exited; an embedding host must keep that
runtime and its resources quarantined. Close is idempotent, and this proof
failure remains sticky across repeated calls so later cleanup cannot
accidentally release the quarantined admission.

## Process and session options

| Option | Purpose |
| --- | --- |
| `WithExecutablePath` | Set the Claude CLI path (default: search `PATH`). |
| `WithHome` | Set `CLAUDE_CONFIG_DIR` for launched Claude processes. |
| `WithScratchDir` | Parent directory for ephemeral on-disk materialization, created `0700` when missing (default: system temp). |
| `WithDefaultModel` | Default Claude model for new sessions. |
| `WithEnv` | Merge environment variables into every Claude child. |
| `WithSeedFiles` | Write files into the resolved config dir before launch (requires `WithHome`). |
| `WithSessionStore` | Replace the default in-memory session authority with a host store. |
| `WithSessionStoreLoadTimeout` | Bound store reads used during restore and listing. |
| `WithConcurrencyLimits` | Cap active sessions and concurrent client calls. |
| `WithTurnTimeout` | Bound one prompt turn; expiry fails the turn with cause `timeout` (default: no deadline). |
| `WithRuntimeResourceHooks` | Let an embedding host admit native roots and reserve adapter scratch roots before they are created. |

## Claude-specific options

| Option | Purpose |
| --- | --- |
| `WithClaudeDefaultPermissionMode` | Initial permission mode for new sessions. |
| `WithClaudeDefaultSystemPrompt` | Default system prompt. |
| `WithClaudeHideAuth` | Suppress Claude subscription terminal auth methods. |
| `WithClaudeBareMode` | Launch Claude with `--bare`. |
| `WithClaudeSettingSources` | Select Claude filesystem setting sources (`--setting-sources`). |
| `WithClaudeSettingsFile` | Load a settings overlay via `--settings` (requires `WithHome`). |
| `WithClaudeAllowSkipPermissionsFlag` | Permit Claude's skip-permissions capability flag. |
| `WithClaudeInitializeTimeout` | Bound the Claude control-protocol initialize request. |
| `WithClaudeControlHandlerTimeout` | Bound one inbound Claude control request. |
| `WithClaudeDirectAPI` | Allow the adapter to call the Anthropic API itself (default: enabled). |

### `WithClaudeDirectAPI`

Every other network call this adapter makes happens inside a `claude` child
process. `WithClaudeDirectAPI` governs the one exception: when
[`_claude/rateLimits`](/docs/reference/acp-methods) finds no usage windows in the
harness panel, it reads the account's usage straight from the Anthropic API —
which may issue a billable one-token inference request.

It is enabled by default. Pass `WithClaudeDirectAPI(false)` to forbid the
adapter from contacting any network service on its own behalf; `_claude/rateLimits`
then reports only what the harness prints.

## Request helpers and store types

Request builders: `TextPromptRequest`, `CallForkSession`, `WithSessionRawEvents`,
`WithSessionOutputSchema`, `SetConfigOptionRequest`, `SetModelRequest`,
`DeleteSessionRequest`, `StdioMCPServer`, `HTTPMCPServer`.

`PromptRequest(sessionID, turnNonce, blocks...)` and
`TextPromptRequest(sessionID, turnNonce, text)` require a fresh, unguessable
nonce of at most 4096 bytes for every turn. Use the same nonce with
`CancelRequest(sessionID, turnNonce)` while that turn is active. A blank nonce
or one larger than 4096 bytes leaves the builder's route metadata nil, so the
receiving agent rejects the request or cancellation fail-closed.

`RuntimeResourceHooks` has `AcquireNativeRoot`, `ReserveScratchRoot`,
`ObserveProcess`, `ObserveProcessSnapshot`, and `ObserveStartupStage`
callbacks. Admission callbacks receive one of `runtime`, `session`, `prompt`,
or `discovery` and return an idempotently wrapped release function. Native-root
release happens only after the native controller has stopped; scratch release
happens after deletion. Claude is lockless and emits no home-lock-supervisor
count. Absolute descendant snapshots are emitted only when containment proves
them; startup stages are `spawn`, `readiness`, `configuration`, and `session`
where applicable. A nil callback keeps standalone use unbounded.

Session-store surface: `SessionStore`, `SessionKey`, `SessionSummary`,
`SessionStoreReplacement`, `InMemorySessionStore`, and the constants
`SessionStoreFormat` and `SessionStoreMainSubpath`.
