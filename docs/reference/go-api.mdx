Create an agent with `Serve`:

```go
err := claudeacp.Serve(ctx, input, output,
    claudeacp.WithExecutablePath("/usr/local/bin/claude"),
    claudeacp.WithHome("/tmp/claude-home"),
    claudeacp.WithDefaultModel("sonnet"),
    claudeacp.WithClaudeDefaultPermissionMode("default"),
    claudeacp.WithSessionStore(store),
)
```

Common options:

| Option | Purpose |
| --- | --- |
| `WithExecutablePath` | Set the Claude CLI path. |
| `WithHome` | Set `CLAUDE_CONFIG_DIR` for launched Claude processes. |
| `WithDefaultModel` | Set the default Claude model string. |
| `WithEnv` | Add environment variables for Claude children. |
| `WithSessionStore` | Install durable transcript storage. |
| `WithConcurrencyLimits` | Set active session and prompt caps. |
| `WithClaudeBareMode` | Launch Claude with `--bare`. |
| `WithClaudeSettingSources` | Select Claude setting sources. |

Request helpers include `TextPromptRequest`, `CallForkSession`,
`WithSessionRawEvents`, `WithSessionOutputSchema`, `SetConfigOptionRequest`,
`SetModelRequest`, and `DeleteSessionRequest`.
