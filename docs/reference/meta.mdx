---
title: "Metadata"
description: "The _meta.claude vocabulary"
---

The adapter uses only `_meta.claude` for Claude-specific public metadata.

Initialize metadata includes capability descriptors for session fork, raw
events, session storage, structured output, elicitation, and model metadata.

Session options are accepted under:

```json
{
  "_meta": {
    "claude": {
      "options": {
        "model": "sonnet",
        "mode": "default",
        "thoughtLevel": "medium",
        "outputSchema": {}
      },
      "rawEvent": {
        "enabled": true
      }
    }
  }
}
```

Unknown keys in the Claude namespace are rejected on lifecycle requests.
Foreign metadata namespaces are preserved for their owners.
