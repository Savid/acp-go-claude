Session import lets a host upload strict
[Claude JSONL session rows](https://code.claude.com/docs/en/sessions) and
later use [`session/load` or `session/resume`](/docs/core/sessions#load-vs-resume).
It is a Claude-specific ACP extension, not a portable ACP method.

## One-shot import

Call `_claude/session/import` with all entries. Extension method naming follows
ACP [`_meta` and extension](https://agentclientprotocol.com/protocol/extensibility)
conventions, and the implemented method list is in
[ACP methods](/docs/reference/acp-methods#claude-specific-extension-methods):

```json
{
  "sessionId": "00000000-0000-4000-8000-000000000000",
  "cwd": "/workspace/project",
  "format": "claude-jsonl",
  "entries": [
    { "type": "summary", "summary": "..." }
  ]
}
```

The method validates and commits in one call.

## Chunked import

1. Call `_claude/session/importChunk`.
2. Repeat with the same `importId` and increasing `offset`.
3. Call `_claude/session/commitImport`.
4. Or call `_claude/session/abortImport`.

Chunk response:

```json
{
  "importId": "...",
  "sessionId": "...",
  "cwd": "/workspace/project",
  "format": "claude-jsonl",
  "offset": 100,
  "entries": 100,
  "bytes": 12345
}
```

Commit response includes the SHA-256 hash of imported rows.

## Validation

- `sessionId` is required and must be UUID-shaped.
- `cwd` is required and must be absolute.
- `format`, when provided, must be `claude-jsonl`.
- `subpath`, when provided, must be a safe relative session subpath.
- Each entry must be one JSON object.
- Max line size is 10 MiB.
- Max chunk size is 10,000 entries.
- Max import size is 100,000 entries or 100 MiB.

## Storage

Committed imports write to the configured
[SessionStore](/docs/features/session-store). If no external store is
configured, imports use the agent's process-local in-memory store. The Go
interfaces are documented in [Go API](/docs/reference/go-api#sessionstore).
