## Update mapping

During a prompt turn, Claude stream frames are translated into ACP session
updates:

| Update | Source |
| --- | --- |
| assistant message chunks | Claude assistant text |
| thought chunks | Claude thinking text |
| tool call | Claude tool start/input |
| tool result | Claude tool result |
| plan | Claude plan updates |
| available commands | Claude slash-command set (and refreshes) |
| usage | Claude usage counters (`_meta.claude.usage`) |
| session info | title and state changes |

## Related channels

- Raw Claude frames, when enabled, arrive separately on `_claude/rawEvent` and
  are **not** session updates — see [Raw events](/docs/features/raw-events).
- A turn *failure* is a JSON-RPC error on `session/prompt`, not an update — see
  the failure contract in [ACP methods](/docs/reference/acp-methods).
- Structured-output results are returned in prompt metadata under
  `_meta.claude.structuredOutput`, not as a session update.
- Subagent output flattens into this same update stream, tagged with
  `_meta.claude.parentToolUseId`; untagged updates are the main agent — see
  [Metadata](/docs/reference/meta).
